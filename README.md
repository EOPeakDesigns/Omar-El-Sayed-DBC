# Omar El-Sayed Digital Business Card

A premium mobile-first digital business card built with **HTML5, CSS3, and Vanilla JavaScript**. This project is designed to feel like a polished mobile app while staying lightweight, fast, accessible, and easy to deploy on GitHub or any static hosting platform.

## Overview

This card was built as a production-ready personal branding experience for smartphones. It includes one-tap contact actions, QR sharing, downloadable contact support, dark mode, RTL support, installable PWA behavior, and an elegant modern UI optimized for mobile devices.

## Features

- Mobile-first responsive layout
- Premium single-card UI
- QR code modal with downloadable QR image
- Save contact as `.vcf`
- One-tap actions for phone, email, website, and maps
- Social media links
- Clipboard copy support
- Dark mode
- English and Arabic support with RTL
- PWA support with manifest and service worker
- Offline-friendly app shell caching
- Accessible keyboard and focus behavior

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6 modules)
- Web App Manifest
- Service Worker
